Reflection Journal
Week of: September 23, 2026
My goal this week
My goal was to build a working trip planning app for Angeles City, Pampanga.

I wanted users to save trips, destinations, activities, and notes.

I also wanted to add Google Maps features.

What I did
I built the TripList client using React and Vite.

I added a trip page where users can:

Create trips
Add destinations
Add activities
Add notes
Set destination status to Next, OTW, or Done
I added Google Maps support.

Users can view destinations on a map.

Users can also add a place from the map to their destination list.

I added a Start button that opens Google Maps directions.

I added activity suggestions for:

Sisig
Coffee
Restaurants
Breakfast
Desserts
Nightlife
I improved the design with an Angeles City and Pampanga theme.

I added starter trip data so the app works when opened for the first time.

I pushed the project to GitHub and tested the client build.

What blocked me
The project still uses browser storage in demo mode.

The Express API and PostgreSQL database are not fully connected to the client.

Google Maps needs an API key for the full map features.

GitHub Pages also needed to be enabled before the live website could work.

What I learned
I learned how to build a trip planner with React.

I learned how to save data in browser storage.

I learned how to use Google Maps links, map locations, and directions.

I learned that Google Maps API keys must be restricted and kept safe.

I learned how to use Git and GitHub to save and publish project changes.

I also learned that a project needs clear documentation and testing, not only a working interface.
